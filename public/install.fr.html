Installer SRS Flashcards sur votre écran d’accueil

Retrouvez l’expérience d’une application, avec l’accès hors ligne et le lancement depuis l’écran d’accueil.

⚠️ Version préliminaire : cette application est encore en préversion. La mise à jour ne fonctionne pas correctement pour l’instant : pour mettre à jour, il faut supprimer puis réinstaller complètement l’application. La restauration des données n’étant pas terminée, cela veut dire que votre progression sera perdue à chaque mise à jour.

Remarque : vous pouvez télécharger vos données de progression pour les sauvegarder, mais leur restauration n’est pas encore possible.

Instructions Android

1

Touchez le menu à trois points en haut à droite

2

Touchez Ajouter à l’écran d’accueil

3

Choisissez « Installer l’application » puis « Ajouter à l’écran d’accueil »

Remarque : si l’option d’installation n’apparaît pas, essayez avec Chrome et vérifiez que vous êtes bien sur la bonne page.

Instructions iPhone, iOS et macOS

1

Touchez l’icône de partage (le carré avec une flèche) en bas de l’écran (il faut parfois faire défiler un peu vers le haut pour la voir)

Sur macOS, vous pouvez aussi utiliser le bouton carré avec une flèche en haut à droite de Safari. Dans Chrome, un bouton d’installation se trouve à droite de la barre d’adresse.

2

Choisissez « Sur l’écran d’accueil » (ou « Ajouter au Dock » sur macOS)

3

Confirmez en touchant « Ajouter » en haut à droite

Remarque : iOS 16.4 ou plus récent est recommandé pour profiter de toutes les fonctions des PWA.

Accès direct par le web

À propos de la version web :

Ceci est la version web de l’application. Elle en fait moins que la version installée. C’est un bon moyen de l’essayer sans rien installer, mais nous vous conseillons de l’installer pour en profiter pleinement.

  • Votre progression sera perdue quand le navigateur videra le cache du site
  • Aucune notification pour vous rappeler de réviser vos cartes
  • Aucun accès hors ligne : une connexion internet est nécessaire
  • Certaines fonctions peuvent ne pas se comporter comme prévu

Après l’installation

Une fois installée, vous pouvez :

  • La lancer comme n’importe quelle application
  • L’utiliser hors ligne, dans les transports ou en voyage
  • Recevoir les mises à jour automatiquement

Désinstaller

  • Android :
    • Appui long sur l’icône > Infos sur l’appli > Désinstaller
    • Paramètres > Applications > SRS Flashcards > Désinstaller
    • Paramètres > Stockage > Applications > Chrome > Effacer le stockage > Stockage des sites > Gérer > SRS Flashcards > Supprimer les données
  • iOS : appui long sur l’icône > Supprimer l’app

En savoir plus sur les PWA (applications web installables)

Les PWA (Progressive Web Apps) sont des sites web qui se comportent comme des applications : on peut les installer, elles fonctionnent hors ligne et elles envoient des notifications.
